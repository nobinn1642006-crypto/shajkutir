## 📁 প্রজেক্ট ওভারভিউ (Minimalist Redesign Overview)

আপনার নির্দেশনা অনুযায়ী ওয়েবসাইটটি সম্পূর্ণ **সিম্পল, মার্জিত (Simple & Minimal) ও আল্ট্রা-লাইটওয়েট** করে আপডেট করা হয়েছে:

1. **সার্কুলার অরবিট শোকেস (3D Orbit):** মাঝখানে শারদীয় প্রদীপ/পদ্ম এবং তার চারপাশে ৫টি শাড়ির ত্রিমাত্রিক ঘূর্ণন। মোবাইল ও ডেস্কটপ উভয়েই ১০০% রেসপন্সিভ।
2. **ডিরেক্ট কন্টাক্ট লিঙ্কস (ফুটার):**
   - **ফোন:** সরাসরি কাস্টমার সাপোর্টে কল (`tel:+8801712345678`)
   - **জিমেইল কম্পোজ লিঙ্ক:** কাস্টমার ক্লিক করলেই স্বয়ংক্রিয়ভাবে সাজকুটিরের ঠিকানাসহ নতুন ইমেইল কম্পোজ উইন্ডো ওপেন হবে (`https://mail.google.com/mail/?view=cm&fs=1&to=shajkutir@gmail.com&su=...`)
   - **ফেসবুক পেজ:** সরাসরি ফেসবুক পেজের ভেরিফাইড লিঙ্ক
3. **প্রোডাক্ট ছবি অপ্টিমাইজেশন (Only .webp):**
   - শাড়ির ফোল্ডারগুলো থেকে সমস্ত অপ্রয়োজনীয় `.jpg`, `.png`, `.svg` মুছে ফেলে **শুধুমাত্র হাই-কোয়ালিটি ও সুপার-ফাস্ট লোডিং `.webp`** ছবি রাখা হয়েছে।
   - ১টি ক্যাটাগরির ভেতরে অনায়াসে **৪টির বেশি (যেমন ৫, ৬, ৮ বা ১০টি) ছবি** যুক্ত করা যায়। থাম্বনেইল রো-তে স্বয়ংক্রিয় স্মুথ স্ক্রোলিং ও ফুলস্ক্রিন লাইটবক্স কাউন্টার কাজ করবে।
4. **কালার ও ডিজাইন ভ্যারিয়েন্ট ট্র্যাকিং (Variant Selection):**
   - কাস্টমার যখনই কোনো শাড়ির নির্দিষ্ট থাম্বনেইলে ক্লিক করবেন, সেই কালার/ডিজাইনটি নির্বাচিত হবে (যেমন: `ডিজাইন ১ (লাল পার)`, `ডিজাইন ২ (কপার জরি)` ইত্যাদি)।
   - অর্ডার ফর্ম ও অর্ডার কনফার্মেশন স্ক্রিনে নির্বাচিত ডিজাইনটি স্পষ্টভাবে প্রদর্শিত হবে।
   - গুগল শিটে স্বয়ংক্রিয়ভাবে আলাদা কলামে (`Selected Color / Design`) নির্বাচিত ডিজাইনের নাম এবং `=IMAGE(T...)` ফর্মুলায় নির্বাচিত কালারের থাম্বনেইল ছবি যুক্ত হবে।
5. **পরিমাপ ও ব্লাউজ পিস গাইড (Size & Dimension Guide):**
   - শাড়ির ১২ হাত দৈর্ঘ্য, ৪৬-৪৮ ইঞ্চি বহর ও ৮৫ সেমি ব্লাউজ পিসের পরিচ্ছন্ন পপআপ গাইড।
6. **লাইভ সোশ্যাল প্রুফ ও সাম্প্রতিক অর্ডার অ্যালার্ট (Live Recent Order Ticker):**
   - স্ক্রিনের নিচে মার্জিত একটি ছোট টোস্ট যা কাস্টমারকে বিরক্ত না করে সাম্প্রতিক অর্ডারের তথ্য প্রদর্শন করে কনভার্সন বৃদ্ধি করে। শপিং বা চেকআউটের সময় এটি নিজে থেকেই ডিসপ্লে বন্ধ রাখে।

## 🔍 সহজে অর্ডার ট্র্যাক করার সহজ উপায় (Easy Order Tracking Guide)

### ১. স্টোর ওনারের জন্য (Store Admin Tracking):
- **গুগল শিট ড্যাশবোর্ড:** আপনার গুগল শিটে প্রতি সেকেন্ডে নতুন অর্ডার অটোমেটিক চলে আসে। কলাম **I**-তে নির্বাচিত ডিজাইনের নাম এবং কলাম **W**-তে শাড়ির থাম্বনেইল ছবি দেখে প্যাকেজিং টিম কোনো ভুল ছাড়া সঠিক শাড়িটি পার্সেল করতে পারবে।
- **স্বয়ংক্রিয় ইমেইল অ্যালার্ট:** কাস্টমার অর্ডার করার সাথে সাথেই আপনার জিমেইলে (`shajkutir@gmail.com`) অর্ডারের সমস্ত তথ্য (নাম, ফোন, ঠিকানা, নির্বাচিত ডিজাইন) সহ অ্যালার্ট চলে যাবে।
- **স্টেটাস ম্যানেজমেন্ট:** কলাম **V**-তে আপনি ড্রপডাউন করে দিতে পারেন: `New` ➔ `Confirmed` ➔ `Packaging` ➔ `Shipped (Steadfast/Pathao)` ➔ `Delivered`।

### ২. কাস্টমারের জন্য (Customer Tracking):
- অর্ডার কনফার্ম করার সাথে সাথে কাস্টমার স্ক্রিনে একটি ইউনিক **অর্ডার নম্বর** (যেমন: `SW-5832`) এবং অর্ডারের সম্পূর্ণ বিবরণী দেখতে পাবেন।
- কাস্টমার সরাসরি যেকোনো অনুসন্ধানে পেজের ফুটারে দেওয়া ফোন নম্বরে কল করতে পারবেন অথবা এক ক্লিকে জিমেইল বা ফেসবুক পেজে যোগাযোগ করতে পারবেন।
- কুরিয়ারে (যেমন: Steadfast বা Pathao) পার্সেল এন্ট্রি করার পর কুরিয়ার থেকে কাস্টমারের মোবাইলে স্বয়ংক্রিয়ভাবে ট্র্যাকিং লিঙ্কসহ SMS চলে যায়।

## 🖼️ কিভাবে নতুন ছবি যোগ করবেন (Adding 4+ Images per Saree)

`data/products.js` ফাইলে প্রতিটি শাড়ির `images` অ্যারেতে আপনি ইচ্ছামতো `.webp` ছবি যোগ করতে পারেন:

```javascript
images: [
  { url: 'images/products/S001/1.webp', name_bn: '১ নং ডিজাইন (লাল পার)', name_en: 'Design 1 (Red Border)' },
  { url: 'images/products/S001/2.webp', name_bn: '২ নং ডিজাইন (কপার বুনন)', name_en: 'Design 2 (Copper Weave)' },
  { url: 'images/products/S001/3.webp', name_bn: '৩ নং ডিজাইন (আঁচল নকশা)', name_en: 'Design 3 (Pallu Motif)' },
  { url: 'images/products/S001/4.webp', name_bn: '৪ নং ডিজাইন (ফুল ভিউ)', name_en: 'Design 4 (Full View)' },
  { url: 'images/products/S001/5.webp', name_bn: '৫ নং ডিজাইন (স্পেশাল কালার)', name_en: 'Design 5 (Special Color)' } // ৫ নম্বর বা তার বেশি ছবি
]
```

ছবিগুলো সংশ্লিষ্ট শাড়ির ফোল্ডারে (যেমন `images/products/S001/5.webp`) রেখে দিলেই ওয়েবসাইটে স্বয়ংক্রিয়ভাবে চলে আসবে।
